# 通信表・指導要録 所見作成支援アプリ

委員会・係・行事の係・行動の記録（10項目）・日常の見取りをもとに、
**通信表用（敬体）** と **指導要録用（常体・短め）** の所見を自動で組み立てるアプリです。
道徳、総合的な学習の時間の所見にも対応し、最後に全員分をまとめて確認してエクセルに出力できます。

- インストール不要。`index.html` をブラウザで開くだけで使えます。
- 外部ライブラリなし・通信なし。入力内容はその端末のブラウザ内にだけ保存されます。

## 2つの版

同じ文例・同じ組み立て方で、2つの版があります。どちらを使っても結果は同じです。

| | ブラウザ版 | エクセル版 |
| --- | --- | --- |
| 使い方 | `index.html` を開く | `dist/所見作成支援.xlsx` を開く |
| 保存先 | ブラウザ内（localStorage） | ブックそのもの |
| 生成 | 画面の操作で自動 | マクロ `GenerateAll` を実行 |
| 下ごしらえ | 不要 | 最初に一度だけ VBA の取り込みが必要 |

エクセル版の詳細は下の「エクセル版」を参照してください。

## 個人情報について

**児童生徒の個人情報は入力しません。**

- 氏名・住所などの入力欄はありません。管理は **出席番号のみ** です。
- 入力内容は外部に送信されません（保存先はブラウザの localStorage）。
- 貼り付けたテキストや所見の中に氏名らしい表現（〜さん・くん など）があると警告します。
  「お母さん」「パン屋さん」など氏名でない語は警告しません。
- 端末を手放すときや年度が変わったときは、画面右上の「データを全消去」で消してください。

## 使い方

1. `index.html` をダブルクリックしてブラウザで開きます。
2. 画面上部のタブを **1 → 8** の順に進めます。

| タブ | 入力するもの |
| --- | --- |
| 1. 設定 | 学期・出席番号の最大・**文字数**・**所見に入れる項目と順番**・行動10項目の順番 |
| 2. 委員会・係 | 委員会名／委員会での役割／活動内容、係名／係の仕事 |
| 3. 行事・行事の係 | 行事名／その行事で担当した係／頑張り（1人3つまで） |
| 4. 行動の記録 | 10項目の ◎ ○ |
| 5. 日常の見取り | その子ならではの具体的な事実（1人3つまで）と文末の文型 |
| 6. 道徳 | 教材名／内容項目／児童の振り返り（1人何行でも） |
| 7. 総合的な学習 | 単元名／探究課題／活動の様子／成果（1人何行でも） |
| 8. 所見の確認・出力 | 全員分をまとめて確認・手直し・エクセル出力 |

### エクセルからの貼り付け

2つの方法があります。

- **表に直接貼り付け**：エクセルで範囲をコピー → 貼り付け先の左上のセルをクリック → `Ctrl+V`。
- **まとめて貼り付け**：各タブの「まとめて貼り付け」を開き、見出し行を含む表を丸ごと貼り付けて「この内容を取り込む」。
  1列目を出席番号として読み取ります。委員会・係と行動の記録は、見出し行があれば列を自動で対応づけます。

行動の記録は ◎ ○ のほか、`A` `B` `@` `o` `〇` なども読み取り、◎ ○ にそろえます。

### 文字数と文体

- 通信表は**敬体（です・ます）**、指導要録は**常体（だ・である）**で作ります。
- 種類ごと（行動・活動・見取り／道徳／総合）に、通信表用・指導要録用の文字数を別々に設定できます。
- 設定した文字数を超えるときは、**優先順位の低い項目から**短い文例に置き換え、
  それでも収まらない文は使いません。使わなかった文は確認画面に
  「文字数の都合で未使用」として表示されるので、入れ替えの判断ができます。

### 項目の順番

学校によって書く順番が違うため、「1. 設定」で並べ替えます。

- **所見に入れる項目と順番**：日常の見取り／委員会／係／行事／行動の記録の順番と使う・使わないの切り替え。
  **上にあるものほど優先**され、文字数に収まらないときは下から削られます。
- **行動の記録の並び順**：10項目の順番。ここでの順番が「4. 行動の記録」の入力表の列の順にもなります。

### 確認と出力

「8. 所見の確認・出力」では、出席番号ごとに6種類の所見（通信表／指導要録 × 行動・活動・見取り／道徳／総合）を並べて確認できます。

- 文ごとに **どの項目から作られた文か** をタグで表示します。
- 文字数超過・未作成・氏名らしい表現は警告します（表示の絞り込みも可能）。
- そのまま書き直せます。手直しした所見は「手直し済み」と表示され、再生成しても上書きされません。
- 「別の文例にする」で言い回しを差し替えられます。
- **エクセルに出力**すると、次の6シートのブックができます。
  - 通信表所見（敬体）／指導要録所見（常体）／チェック一覧／入力データ／道徳（教材別）／総合（単元別）
- CSV 出力・印刷にも対応しています。

## エクセル版

エクセルの中だけで完結する版です。ブラウザ版と同じ文例・同じ組み立て方を VBA に移しています。

### 準備（最初に一度だけ）

エクセルはマクロをファイルに直接埋め込む必要があるため、次の取り込みを一度だけ行います。
**取り込んで `.xlsm` として保存すれば、そのファイルはそのまま配布して使えます。**
学年・学校で使うときは、どなたか一人が作ったものを配れば十分です。

1. `dist/所見作成支援.xlsx` を開き、「Excel マクロ有効ブック (*.xlsm)」として保存し直す
2. `Alt + F11` で VBE（Visual Basic Editor）を開く
3. 「ファイル」→「ファイルのインポート」で `dist/vba/` の4つを順に取り込む
   （`modUtil.bas` / `modTemplates.bas` / `modGenerate.bas` / `modApp.bas`）
4. VBE を閉じて上書き保存する

### 使い方

1. 「設定」で学期・出席番号の最大・文字数・所見に入れる項目と順番を決める
2. 「委員会・係」「行事」「行動の記録」「見取り」「道徳」「総合」に入力する（貼り付け可）
3. `Alt + F8` →「GenerateAll」を実行する
4. 「所見」シートで確認・手直しする

「所見」シートでは、**別案**の数字を変えると言い回しが変わり、**手直し**を「はい」にした行は
作り直しても上書きされません。文字数超過・未使用の文・氏名らしい表現は**警告**欄に出ます。

入力を消すときはマクロ `ClearAllData` を実行します（設定と文例は残ります）。

### 文例を変えるとき

「文例」シートを直すだけで生成結果が変わります（VBA の編集は不要）。
記法はブラウザ版と同じで、`{敬体|常体}` が文体の出し分け、`{{キー}}` が差し込みです。
同じ区分の文例を増やすほど、同じ言い回しが続きにくくなります。

### 作り直すとき

```
python3 tools/build_excel_app.py   # dist/ を作り直す
python3 tools/verify_logic.py      # VBA の手順を JS 版と突き合わせて検証
```

`verify_logic.py` は、VBA と同じ手順を Python で書き起こしたものを
元の JavaScript 版（node 実行）と比較し、移植のずれを検出します。

## 注意

生成される文は**文例の組み合わせ**です。そのまま提出せず、必ず担任がその子の事実と照らして確認・修正してください。
とくに「日常の見取り」で「そのまま使う」を選んだ文の常体変換は機械的な処理のため、指導要録に使う前に必ず読み返してください。

## ファイル構成

```
index.html            画面
css/style.css         見た目
js/util.js            文字数・貼り付け解析・文体変換・保存
js/templates.js       所見の文例（ここを直せば文例を差し替えられます）
js/generate.js        所見の組み立て（順番・文字数調整・文体）
js/xlsx.js            エクセル書き出し（外部ライブラリ不使用）
js/app.js             画面の制御
sample/貼り付けサンプル.txt  貼り付けの練習用データ

vba/modUtil.bas       文字数・テンプレート展開・文体変換（エクセル版）
vba/modTemplates.bas  文例シートの読み込み
vba/modGenerate.bas   所見の組み立て
vba/modApp.bas        シートの読み書きとマクロ本体
tools/build_excel_app.py  エクセル版ブックの生成
tools/verify_logic.py     移植したロジックの検証
dist/                 生成物（ブックと取り込み用の .bas）
```

文例は `js/templates.js` にまとまっています。
`{敬体|常体}` は文体による出し分け、`{{キー}}` は入力内容の差し込みです。

### 動作環境

Chrome / Edge / Firefox / Safari の最近のバージョン。

`index.html` を直接開いた場合、ブラウザによっては出力ファイル名が `download` になることがあります。
そのときはローカルサーバー経由（例：`npx http-server`）で開いてください。
